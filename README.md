# Cisco Small Office Network

## Project Overview

This project involves designing, configuring and testing a simulated small office network using Cisco Packet Tracer. The aim is to develop practical networking skills and understand how devices communicate within a local area network (LAN).

## Project Objectives

- Design a small office network using a star topology.
- Understand the functions of routers and switches.
- Configure IPv4 addressing and default gateways.
- Test network connectivity.
- Develop network troubleshooting skills.

## Equipment and Software

- Cisco Packet Tracer 9.0.1 (Build 0858)
- Cisco 1941 Router
- Cisco 2960-24TT Switch
- Four PC-PT workstations
- Five copper straight-through Ethernet cables

## Network Topology

Four workstations connect to a central switch, which connects to the router. All five physical links are operational. IP connectivity testing is pending.
